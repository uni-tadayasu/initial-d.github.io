# 頭文字Dブラウザゲーム — 強化CPU・オンラインCPU・フレンド機能

## 主な変更点

- ソロ：入門・標準・上級・伝説・鬼神の5段階AI。先読み減速、ライン取り、追い抜き、路面・車両性能に対応。
- オンライン：ホストがCPU台数と強さを選択。人間とCPU合わせて最大8台。1人＋CPUでも開始可能。
- CPUは部屋のホスト側でシミュレーションしてサーバー経由で全参加者へ配信。ホストが落ちた場合はCPU更新が停止するため、ホストが再接続して下さい。
- フレンド：公開フレンドコード、申請→承認、オンライン表示、ルーム招待、削除、端末移行キー。
- フレンドの秘密の引き継ぎキーを他人に渡さないでください。フレンドは自宅サーバーの `data/friends.sqlite3` に保存されます。

## GitHub Pages に更新するファイル

`index.html` / `online8.js` / `rival-ai.js` / `social-friends.js` を必ず更新。
同梱の `save-sync.js`, `online-config.js`, `join.html`, `.nojekyll` は既存の仕様との互換を保つためのファイルです。

**注意：既に設定済みの `online-config.js` を未設定の配布版で上書きしないでください。** 固定URL/一時URL自動更新で生成した設定を維持してください。

## Windows サーバー更新

- 更新前に、古いBAT/サーバーの画面を閉じる。サーバーを止めずに更新しても、実行中の古いPythonプロセスには反映されません。
- 新しい万能BAT `TOUGE_UNIVERSAL_AUTO_CPU_FRIENDS.bat` は最新サーバーコードを内蔵。以前と同じフォルダに置いて起動すると、古いコードを差し替え、前回のGitHubリポジトリ設定・クラウドセーブを維持します。
- 固定URLサーバーをZIPで使う場合は、WindowsサーバーZIPを既存フォルダに展開してファイルを上書きする。`data/` と `fixed_url.json` は消さないこと。旧サービスを終了してから `START_FIXED_SERVER.bat` で起動。
- 既存サーバーのヘルスチェックは `http://127.0.0.1:47817/healthz`。更新後のJSONには `"friends":true,"cpuRivals":true` が含まれます。

## ゲーム内の使い方

ソロ：タイトル画面「CPU難易度」を選択 →「すぐソロレース」または「グランプリ」。
オンライン：「友達とオンライン」→「部屋を作成」→「オンラインCPU対戦設定」で台数0〜7、難易度を選択 →「一斉レース開始」。人間が増えたら自動的にCPU枠が減ります。
フレンド：「友達とオンライン」→「👥 フレンド / 招待」を開き、自分のフレンドコードをコピー → 相手が申請、本人が承認 → 同じ場所から部屋招待。

## 制約

- 最大8台は「人間＋CPU」の合計であり、人間8人＋CPU7台ではありません。
- オンラインのCPUはホスト権限で計算されます。完全なサーバー権威型AIではありません。
- レースデータはカジュアル対戦向けであり、チート対策やフル物理同期は保証しません。
- GitHub PagesだけではWebSocketサーバーは動きません。自宅PCのサーバーと公開WSSトンネルが必要です。
- 既存のセーブデータ、ショップ、車両、コース、BGMの形式は変更していません。
