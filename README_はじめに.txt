尾文字Z V36 — GitHub Pages公開パック（SEO + Stripeカード決済準備）
==============================================================

■ 公開するファイル
このZIP内の全ファイル（index.html、紹介ページ、og-image.jpg、sitemap.xml、robots.txt、.nojekyll等）を
GitHubリポジトリの公開ルートへアップロードします。

想定公開URL: https://uni-tadayasu.github.io/initial-d.github.io/
URLが異なる場合は、canonical、OGP、JSON-LD、サイトマップのURLを更新する必要があります。

■ SEOの公開後設定
1. GitHub Pagesの表示・内部リンクと画像の読込を確認する。
2. Google Search Consoleに公開URLを登録・所有権確認する。
3. sitemap.xmlを登録し、インデックス登録状況を確認する。
4. 公式名「尾文字Z」をサイト、SNS、公式説明ページで統一して告知する。
検索1位は保証されません。

■ クレジットカード課金
☆1段階3,000円、☆1→☆5で合計12,000円。
Stripe Payment Linksの本番リンク（3,000／6,000／9,000／12,000円）と
販売者による有効な「特定商取引法に基づく表記」HTTPS URLが設定されるまでは、支払い受付は無効です。
設定はHTML内の「const MERCHANT」で行います。便利なオフライン設定ツールは、別の非公開パックにあります。
決済後の☆付与は自動ではありません。Stripeで入金確認後、運営者が署名付きコードを発行して反映します。

■ セキュリティ
GitHub公開ファイルにStripe秘密鍵、銀行口座番号、パスワード、運営者用署名秘密鍵を入れないでください。
入金先銀行口座はStripeダッシュボードでのみ管理します。
運営者専用パックは絶対にGitHubへアップロードしないでください。

■ 運用上の注意
HTML単体ではセーブデータや有料ステータスの改変を完全には防げません。
正式な有料運用にはStripeの利用規約・日本の通信販売関連表示・返金や問い合わせ方針への対応が必要です。
