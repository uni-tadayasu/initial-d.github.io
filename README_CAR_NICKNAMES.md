# 頭文字Dブラウザゲーム — 愛車のニックネーム対応アップデート

## 追加機能

- **購入済み車両それぞれに独立した愛車名**を最大20文字で設定できます。無料・何度でも変更可能です。
- 名前を登録していない車は、これまで通り車種名を表示します。
- ガレージの詳細画面、所有車一覧、ショップ、ソロ・オンラインのレースHUD・順位表・車体近くの名前表示に反映します。
- 8人オンラインロビーではドライバー名と愛車名を区別して表示します。
- ブラウザのセーブ（localStorage）、JSONのセーブ書出・読込、端末間クラウド同期の対象です。

## 愛車名の変更方法

1. ゲームを開き、**ガレージ / 車種変更**を選択します。
2. 購入済みの車を選ぶと、詳細に **「🏷️ 愛車のニックネーム」** が表示されます。
3. 好きな名前を入力し **「保存」** を押します。
4. 名前を元に戻したいときは **「解除」** を押します。
5. 所有車ショップからも **「🏷 愛車名を設定」** を選んで変更できます。

名前を設定すると、レース中は `白い秋名`、オンライン対戦では `ドライバー名 / 白い秋名` のように表示します。

## GitHub Pages の更新

完成版ZIPのファイルをGitHub Pagesの公開フォルダへ上書きしてください。**特に `index.html` と `online8.js` の両方を更新**してください。`save-sync.js` は従来のセーブ同期機能を維持するため同梱しています。

## Windows 自宅PCサーバーの更新

1. 現在のサーバーBATを終了します。
2. `data/save_vault.sqlite3` のバックアップを取ります（既存の `BACKUP_SAVES.bat` も利用できます）。
3. Windowsサーバー用ZIPを展開し、旧サーバーのフォルダへ必要ファイルを上書きします。**`data/` フォルダは削除しないでください。**
4. `START_ONLINE.bat` か `START_LAN.bat` で起動し直します。

今回、オンラインで相手に愛車名を送るため、サーバーの `room_server8.py` も更新が必要です。旧サーバーは新しい愛車名データを他の参加者に配信しません。

## 端末間同期

iPhone・Android・PCで同一の同期コードを設定していれば、名前変更もセーブの一部として同期されます。同期の反映には自宅PCのサーバーが稼働している必要があります。複数端末で異なる更新を同時に行った場合は、以前と同様に保存競合の確認が必要です。

## 引き継ぎについて

以前のセーブ形式（バージョン3）はそのまま利用できます。既存の車両・コイン・改造・実績は初期化しません。名前用のフィールドがない旧データは「名前未設定」として処理されます。

## 動作検証

- ブラウザ上の名前入力、保存・解除、車種ごとの保存、レースHUD・順位表表示
- 8人参加の中継、9人目の拒否、愛車名のロビー表示と変更通知、レース走行データへの愛車名反映
- サーバーへのセーブ保存と再取得（愛車名を維持）

実際のiPhone・Android・離れた回線での動作は未確認です。自宅PCの公開中継にはHTTPS/WSSが必要です。GitHub Pagesだけでは中継サーバーを稼働できません。
