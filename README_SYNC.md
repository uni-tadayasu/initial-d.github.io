# 頭文字Dブラウザゲーム — 端末間クラウドセーブ＋8人オンライン対戦

## できること

- iPhone（Safari）・Android（Chrome等）・PC（Chrome/Edge等）の**双方向セーブ同期**。
- コイン、所有車、改造、外装カスタム、購入済みパーツ、累計走行/勝利/ドリフト、固定実績、**無期限の段階実績**、自己ベスト、選択車を同期。
- データ変更後は数秒後に自動送信。別端末は起動時およびおおむね30秒間隔（画面が有効な場合）で新しいデータを取得。
- 通信切断中も各端末でローカル保存。再接続時に再試行。
- **同時に別々の変更があった場合は自動上書きしない**。クラウド優先・この端末優先を選択。
- 既存の最大8人対戦・部屋コード・ショップ・GPX/3Dインポート等は維持。

## Windows 自宅PC（必須）

1. このZIPを**すべて解凍**し、同じフォルダ内の `START_SAVE_AND_ONLINE.bat` または `START_ONLINE.bat` を起動。
2. Python 3.11以降を用意し、PythonのPATHを設定。初回は `websockets` が自動導入されます。
3. Cloudflare一時トンネルが成功すると、`https://xxxx.trycloudflare.com/` と `wss://xxxx.trycloudflare.com/ws` が表示されます。
4. **最も簡単な方法**：PC・iPhone・Androidの全端末で上記のHTTPS公開URLを開く。ゲームも同期サーバーも自動で同じPCへつながります。GitHub Pagesでプレイする場合は `online-config.js` の `relayUrl` に表示された `/ws` のWSS URLを設定するか、ゲーム内で中継URLを入力します。
5. ゲームメニューの「☁️ iPhone・Android・PCとセーブを自動同期」→「データ管理」を開き、1台目で「新規同期コード発行」。**大切な同期コードを安全に控える**。
6. 2台目以降でもゲームを開き、同じ同期コードを入力し「別端末のコードで連携」。同期後は自動更新されます。

**注意:** GitHub Pagesだけではサーバーは動作しません。自宅PCのサーバーが停止している間はローカルプレイのみできますが、端末間で即時同期されません。再起動後に自動再試行します。Cloudflareの一時URLは再起動時に変わるため、永続運用には名前付きトンネル＋固定ドメインを推奨します。サーバー本体のDBは同じPCのフォルダに残るため、URLが変わっても同期コードとデータは保持されます。

## 実績の成長

従来の**16件の固定実績**に加え、**9つの連続実績**を追加。完走、勝利、走行距離、ドリフト、オンライン対戦、改造、ドレスアップ、累計獲得、累計消費が対象です。各系列で目標を達成・報酬受取すると、次の達成段階がその場で追加生成されます。固定の最終段階はありません。端末間で受取済み段階も共有します。

「永遠」はゲーム設計上の**事前に設定された最終段階がない**という意味です。実際の保存容量、数値演算、端末やサーバーの耐用年数は無限ではありません。

## セーブデータの場所とバックアップ

- 自動クラウド保存先：`data/save_vault.sqlite3`（自宅PC上）。サーバー再起動でも継続して保持。
- `BACKUP_SAVES.bat` で、サーバー稼働中でも整合性のあるSQLiteバックアップを `backups/` に作成可能。定期的に外部ストレージにもコピーしてください。
- DBを削除するとクラウドセーブが消えます。**GitHubへの公開アップロードは禁止**。DBにはセーブデータが暗号化されずに含まれます。
- 同期コードは128ビットのランダム秘密鍵（公開してはいけません）。サーバーではコードのSHA-256ハッシュのみ保存します。コードをなくすと復元できません。
- iOS Safariのブラウザデータ削除で端末側の保存・同期コードが消えることがあります。コードの控えとJSONバックアップを推奨します。
- 暗号化されるのはWSS経由の**通信中**です。サーバー上のセーブファイル自体の暗号化は行っていません。
- 車両の外部GLB/OBJモデル本体、GPX/DEMデータ、BGM音声そのもの、ゴーストの軌跡は同期対象外です。再度インポートしてください。
- コインや成績はブラウザで編集可能なため、これは**信頼関係のある友人向け**の仕様です。サーバー側で不正チート検証・課金・安全な公開ランキングは提供していません。

## 同時更新／上書き競合

複数の端末で同時に変更した場合、「保存競合」が表示されます。二重にコインを増減させる危険があるため**自動合算しません**。どちらのデータを残すかを選んでください。

- **クラウド優先**：この端末のローカルセーブをクラウドに置き換える。
- **この端末優先**：クラウドにあるセーブを現在の端末のデータで上書きする。
- いずれも確認ダイアログが表示されます。復元前のバックアップは「復元前バックアップ」から保存可能。

## 配布ファイル

- `index.html` : クラウド同期とエンドレス実績を組み込んだゲーム。
- `online8.js` : 8人対戦。
- `online-config.js` : GitHub Pages等で使うWSS中継先の設定。
- `save-sync.js` : 端末同期UIとWebSocketセーブ送受信。
- `room_server8.py`・`save_vault.py` : 自宅PCの中継・保存サーバー。
- `START_8PLAYER.bat` / `START_SAVE_AND_ONLINE.bat` : サーバー起動。
- `BACKUP_SAVES.bat` : 保存DBのバックアップ。

**実際のiPhone/Android端末とCloudflareを経由した通信の最終確認は、使用するPCとネットワーク上で行ってください。**
