# 頭文字Dブラウザゲーム — GitHub Pages 最大8人オンライン接続

このフォルダのファイルを **GitHub Pages の公開フォルダ（リポジトリのルート等）に配置**します。

## ファイル一覧

| ファイル | 用途 |
|---|---|
| `index.html` | 8人対応済みのゲーム本体。以前の版と置き換えてください |
| `online8.js` | 8人ロビー・接続・レース・順位・車両表示 |
| `online-config.js` | 固定の中継URLを設定したい場合に使う設定ファイル。空欄でも可 |
| `join.html` | 8文字の部屋コードだけで参加できる補助ページ |
| `.nojekyll` | GitHub Pages用の設定 |

**重要:** 旧版の `index.html` に追加ファイルを置いただけでは8人対戦になりません。
必ず同梱の8人対応版 `index.html` に一度置き換えてください。

## 最も簡単な接続手順（ホストのみ中継URLを設定）

1. GitHubのリポジトリに上記5ファイルを置き、**Settings → Pages** で `main` ブランチのルートを公開してください。
2. サーバー用ZIPを自宅のWindows PCで展開し、`START_ONLINE.bat` をダブルクリックしてください。
3. 画面に表示された一時的な `wss://xxxxx.trycloudflare.com/ws` をコピーしてください。
4. ホストがGitHub Pagesで公開中の `index.html` を開き、**「友達とオンライン」→「通信サーバーURLを設定（最初のホストのみ）」** を開き、そのWSS URLを貼り付けます。入力欄からフォーカスを外すと保存します。
5. **「部屋を作成」** を押します。8文字コードと参加人数が表示されます。
6. **「招待リンクをコピー」** を押して友達へ送ります。招待リンクには中継URLと部屋コードが含まれます。
7. 友達が招待リンクを開くと **自動的にその部屋へ参加** します。2人〜8人が集まったら、ホストが **「一斉レース開始」** を押します。

**友達が中継URLを入力する必要はありません。** コードだけで参加する場合は、相手も同じ中継サーバーURLを設定しておく必要があります。

## さらに便利にするには

- 固定アドレスのWSSサーバーがある場合は `online-config.js` の `relayUrl` に `wss://example.com/ws` を設定します。これでホストの貼り付けも不要です。
- 一時Cloudflare TunnelはURLが再起動ごとに変わるので、長期間の運用にはCloudflareの**名前付きトンネル＋独自ドメイン**が適しています。
- 代替：参加者全員が、PCサーバーの発行する `https://....trycloudflare.com/` を直接開けば、GitHub Pagesのファイル更新なしで対戦できます。

## GitHubに何をアップロードするか

- 「GitHub追加ファイル」ZIP：`online8.js`・`online-config.js`・`join.html`・`.nojekyll`・このREADME。**旧indexは自分で更新する必要あり。**
- 「GitHub完成版」ZIP：上記に更新済みの `index.html` を加えたもの。**こちらを推奨。**
- 自宅PCサーバーはGitHub Pagesにアップロードする必要はありません（PythonをGitHub Pagesで実行できません）。

## 注意点

- GitHub Pagesは静的ホスティングです。8人用中継サーバーは自宅PCで稼働させる必要があります。
- インターネット接続には **WSS（暗号化されたWebSocket）** が必要です。HTTPSのGitHub Pagesから `ws://` のサーバーへは接続できません。
- 同じブラウザで別タブを開くと、それぞれ別プレイヤーとして扱われます。部屋は最大8枠です。
- 同期するのはコース、天候、開始時刻、選択車種、位置、完走タイムです。ショップの所持コイン等は各端末のローカルデータで、共通アカウントではありません。
- レース物理は各端末で計算します。改ざん防止・ランキングの不正対策は未実装です。
- 一時トンネルや自宅回線は稼働率・同時通信性能を保証しません。公開用の恒久サーバーには別途運用設計が必要です。

## 接続できないとき

1. PCで `START_ONLINE.bat` が起動したままか、`https://xxxx.trycloudflare.com/healthz` が `status: ok` を返すか確認します。
2. `wss://xxxx.trycloudflare.com/ws` の最後の `/ws` が抜けていないか確認します。
3. お互い同じ8人版のゲームを開いているか確認します。
4. 部屋が既に開始済み・満室・別サーバーにある場合は入れません。
5. ブラウザキャッシュを強制更新し、必要ならホストが部屋を作り直してください。
